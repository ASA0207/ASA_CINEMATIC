# ASA 서버 시네마틱 예고편

## GitHub Pages 배포
1. 새 GitHub 저장소를 만듭니다.
2. `index.html` 파일을 저장소 최상위에 업로드합니다.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. 배포 주소에서 페이지를 확인합니다.

## 포함 기능
- 풀스크린 ASA 인트로 / Enter 키 시작 / 시작 시 무음
- 별 파티클 캔버스 / 반응형 모바일 디자인 / 스크롤 리빌 애니메이션
- 6종 콘텐츠 소개 / 평소마 → ASA 스토리 / 진화 타임라인
- 이스터에그: 키보드로 `asa` 입력
- 공유 버튼 / 상단 이동 / 스크롤 진행 표시 / 카드 마우스 반응
- 사용자 선택형 앰비언트 사운드 (저음 신시사이저, 음악 파일 불필요)
- 출시일 미정 표시 (가짜 카운트다운 없음)

## 커스터마이징
- `index.html`의 텍스트와 카드 설명을 직접 수정할 수 있습니다.
- 서버 주소나 디스코드 링크는 제공되지 않아 임의로 삽입하지 않았습니다.
- 별도의 빌드 도구 없이 정적 호스팅에서 실행됩니다.
- 구글 폰트 사용으로 최초 접속 시 인터넷 연결이 필요합니다.
